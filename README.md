# Neural Network Builder GUI

Live page: https://huangandy05.github.io/neural-network-builder-GUI/

A simple browser-based GUI for designing feed-forward neural networks. Users can choose input/output sizes, hidden layers, activation functions, framework style, loss, optimizer, learning rate, and batch size.

The page shows a live network diagram and generates corresponding PyTorch or Keras code with a copy button.

## Local File

Open `neural-network-builder.html` directly in a browser to use it locally.
